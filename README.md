Программа Шахматы написана на C++.

Запускается через Chess.ехе файл.

Программа представляет собой консольное приложение, позволяющее взаимодействовать с виртуальной шахматной доской:

В программе предусмотрено меню, позволяющее пользователю читать шахматную доску из файла формата .txt, просмотреть имеющуюся шахматную доску, 
проверить ситуацию белого короля (что и является главной задачей программы - расчет ситуации для белого короля на имеющейся доске), а также записать имеющуюся доску в файл формата .txt.

Пользователь может также вручную расставлять фигуры на доске по своему усмотрению. 
Однако первую доску необходимо считать из файла. 

Вид файла доски для считывания: где "64" - число клеток на доске; "Castle Black" - название фигуры; "A 1" - позция фигуры.
